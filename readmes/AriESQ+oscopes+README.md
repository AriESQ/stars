## Oscilloscope Hardware
There are cheap ($40 Oscilloscopes available and they all have a similar look, so I'm assuming there is a single chip or reference board being used.

### Korg NTS-2 - $200
https://www.korg.com/us/products/dj/nts_2/  
https://www.korg.com/us/support/download/product/0/916/#manual  
Input Voltage: ±10V max
0-20KHz Bandwidth

This is geared towards audio usage, It has 2 Audio Jacks. Tt has some bells and whistles like Tone Generator, Tuner.

### FNIRSI DSO152 Oscilloscope - $36
https://www.amazon.com/FNIRSI-138-Pro-Oscilloscope-Automotive/dp/B0C6XPVLPZ    
Sampling rate of 2.5MS/s  
200KHz bandwidth

This looks like an example of the common, mass-produced Chinese Oscilloscope. Note it is single input.

### Labrador - $29
https://espotek.com/labrador/  
https://github.com/EspoTek/Labrador
https://www.amazon.com/EspoTek-Labrador-Easy-Use-All/dp/B07CVB7ZJG  
Input: 2 Channels  
Input Voltage: -20V to +20V  
100kHz bandwidth  

This is somewhat of a DIY kit, needs at least a power supply and doesn't come with any leads/inputs; and it relies on a USB device (Phone/Computer) to do the processing; but it appears feature-rich.  

### Hantek 6022BE Laptop PC USB - $65
https://www.amazon.com/Hantek-Oscilloscope-Channels-Handheld-Portable/dp/0201336421  
Input: 2channels  
20MHz Bandwidth  

USB but windows 10 / Iphone drivers may be an issue.
