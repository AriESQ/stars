no# AAVJ 2025

**AAVJ** is a real-time visual performance and generative media creation environment built in TouchDesigner.  

---

## ✅ Getting Started

1. Use the green "Code > Download ZIP" to download the file structure and extract it to your desired program files location.
2. Download the latest `.toe` file from the [Releases page](https://github.com/anti-alias-arts/AAVJ-2025/releases)
3. Place it in the root of this folder structure
4. Open in TouchDesigner 2023.12230+
