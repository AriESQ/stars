# HackRF Pro: hardware design

HackRF Pro (code name: Praline) is the latest hardware platform for the [HackRF](https://github.com/greatscottgadgets/hackrf) project. It is a Software Defined Radio peripheral capable of transmission or reception of radio signals from 100 kHz to 6 GHz. HackRF Pro is designed to be backward compatible with software and hardware developed for use with HackRF One, whilst introducing many new features and improvements.

Software, project documentation, and support are centralized in the [HackRF](https://github.com/greatscottgadgets/hackrf) repository. Documentation can be viewed online at [Read the Docs](https://hackrf.readthedocs.io/en/latest/).

[HackRF Pro (product page)](https://greatscottgadgets.com/hackrf/pro/) is designed and manufactured by [Great Scott Gadgets](https://greatscottgadgets.com/).
