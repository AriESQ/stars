# Eurorack Hardware Projects

This repository contains my open hardware Eurorack projects, organized in subfolders.
Some of these designs are experimental and may not have been fully tested. Use at your own risk, and feel free to share feedback!


## 1. Video Sync Generator(`sync-gen`)

A derivative of the LZX Cadet Sync Generator with a few changes:  
- Front LED indicates external sync  
- BNC front connectors (lower output is direct sync)  
- Rear connector variants: BNC or RCA 
- PAL/NTSC selection via PCB jumper  
- Easier-to-source VCXO ([Taobao link](https://m.tb.cn/h.gXka5IRwx9xheze?tk=qKCwWulmoJ0))  

## 2. Eurorack Prototyping PCB Set(`proto`)

A set of PCBs to build and prototype Eurorack modules, including front panels, IO boards, and breadboard-style prototyping boards.
