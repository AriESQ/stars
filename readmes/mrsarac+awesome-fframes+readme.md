# Awesome Fframes [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> fframes is a Rust framework for creating videos from code and SVG. This list helps developers find bindings, reusable components and working examples. It also collects authoring tools and places to learn from other projects.

## Official

- [fframes](https://github.com/dmtrKovalenko/fframes) - Rust framework for GPU-rendered video built from code and SVG.
- [Website](https://fframes.studio/) - Getting started, installation guidance and examples from the framework author.

## Crates

- [API documentation](https://docs.rs/fframes/latest/fframes/) - Rust types and functions for composing video projects.
- [cargo-fframes](https://github.com/dmtrKovalenko/fframes/tree/main/cargo-fframes) - Cargo subcommand for generating projects and working with the rendering toolchain.
- [Slabkit](https://github.com/nooga/slabkit-rs) - Rust audio composition tools for scoring video projects.

## Bindings

- [Python bindings](https://github.com/Scr44gr/fframes-py) - Typed Python interface for the rendering framework.

## Agent skills

- [Official video skill](https://github.com/dmtrKovalenko/fframes/tree/main/skills/fframes-video) - Instructions for creating, inspecting and rendering projects with coding assistants.
- [Nara](https://github.com/ryhkml/nara) - Video authoring skill paired with a Rust workspace.

## Components & templates

- [Animated components](https://github.com/Bilaal0x/fframes-components) - Reusable Rust motion components and a gallery.
- [Hello world](https://github.com/dmtrKovalenko/fframes/tree/main/examples/hello-world) - Minimal project for a first rendered video.
- [Shaders](https://github.com/dmtrKovalenko/fframes/tree/main/examples/shaders) - Examples of shader-driven visuals.
- [TikTok](https://github.com/dmtrKovalenko/fframes/tree/main/examples/tiktok) - Short-form video example.
- [Podcast](https://github.com/dmtrKovalenko/fframes/tree/main/examples/podcast) - Audio-led video layout example.
- [Motion graphics](https://github.com/dmtrKovalenko/fframes/tree/main/examples/motion-graphics) - Programmatic animation example.
- [Audio announcement](https://github.com/dmtrKovalenko/fframes/tree/main/examples/audio-announce) - Audio-led announcement video example.
- [Marketing](https://github.com/dmtrKovalenko/fframes/tree/main/examples/marketing) - Promotional video example.

## Showcase (source available)

Source availability does not grant permission to reuse code or assets. Entries marked “no license found” have no detected repository license; inspect each project and obtain permission before reuse. A repository license may not cover bundled media.

- [The Why](https://fframes.studio/the-why/) - Short film with a linked Rust implementation and a walkthrough of its scenes.
- [Node.js port](https://github.com/roryyu/fframes-node) - JavaScript port for rendering and mixing code-driven videos; no license found.
- [Chinese documentation](https://github.com/bbylw/fframes-cn) - Chinese-language framework material; no license found.
- [Claude Reel](https://github.com/wtfsayo/claude-reel) - Motion reel using springs, motion blur and animated typography; MIT licensed.
- [ff-tracking](https://github.com/mrsarac/ff-tracking) - Virtual camera and glyph-tracking animation with synthesized sound; maintainer's own project.
- [ff-unmute](https://github.com/mrsarac/ff-unmute) - Camera flight over a music timeline with beat tracking; maintainer's own project.
- [Mahaganapati Particle Ocean](https://github.com/nikitph/mahaganapati-particle-ocean) - Two-pass particle animation with depth of field and synthesized sound; MIT licensed.
- [Registration system film](https://github.com/lal-ye/registration-system-film) - Code-driven film about a registration-system project; no license found.
- [Actions render demo](https://github.com/lal-ye/fframes-demo) - Example video rendered through GitHub Actions; no license found.
- [Mediabunny comparison](https://github.com/Vanilagy/fframes-mediabunny-benchmark) - Source for a comparison with browser-based video rendering; no license found.
