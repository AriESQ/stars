# AZ0x Open Source Releases

Thanks for your interest in the open source software used by inMusic Brands.

We are happy to comply with the requirements of the open source libraries and projects in use in our products. This repo contains archives of the open source code for the Linux environment in our products. You will find very few changes against the upstream projects here; we aim to submit all relevant patches back up to the mainstream projects.

If you have any queries in line with the open source licenses for these packages please contact developerrelations@inmusicbrands.com.
